# BIR Zonal Values

Private, mobile-friendly lookup app for the current official Philippine BIR
zonal-value workbooks.

## Search rules

- Input format: `Street, Barangay, City`
- Matching order: City → Barangay → Street
- The street must match the workbook's street field; vicinity text is never
  accepted as a street match.
- Generic fallbacks such as `ALL OTHER STREETS`, `ALL OTHER LOTS`, and
  `REMAINING STREETS` are excluded.
- Every classification/value attached to an exact street record is returned.

## One-click update check

The update button checks each Revenue Region against the official BIR page and
workbook URLs. A changed workbook is downloaded server-side, normalized, and
stored as an RDO-level override in the Site's `FILES` R2 binding. Subsequent
searches exclude the older bundled RDO rows and use the updated rows.

The button turns red when the current device has not completed a successful
all-region check in 15 days. The last successful check time is stored on that
device.

## Commands

```bash
npm install
npm run dev
npm run lint
npm test
```

The audited baseline search shards are generated by
`scripts/build_search_data.py` from the normalized BIR master CSV in the parent
CRM workspace.
